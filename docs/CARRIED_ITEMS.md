## X1. Fourteen bars went silent off-machine — CLOSED

**The defect.** Distribution is `git archive HEAD` and nothing else. A reviewer who unpacks that
archive has no curvecast, no meip, and possibly no ruff — and the suite reports green while
eighteen per cent of it did not run. Every one of the fourteen is a bar whose whole purpose is to
compare this repository against something it does not control, which is to say: **the bars that go
silent are exactly the bars that make the repository's claims checkable.**

**Reproduce the count.** Write this plugin outside the tree and run the suite against it:

```python
# absent_all.py -- simulate a clean reviewer machine
import shutil, sys
from pathlib import Path
GONE = Path("C:/__absent__")

def pytest_collection_finish(session):
    names = ("CURVECAST", "MEIP", "CURVECAST_FIXTURE", "FACTOR_SPACE", "GSW_SOURCE", "CASCADE")
    for module in list(sys.modules.values()):
        f = getattr(module, "__file__", None) or ""
        if "deskcraft" in f and "tests" in f:
            for name in names:
                if hasattr(module, name):
                    setattr(module, name, GONE)
            if hasattr(module, "RUFF_CANDIDATES"):
                module.RUFF_CANDIDATES = (GONE / "ruff.exe",)
    shutil.which = lambda *a, **k: None
```

    PYTHONPATH=<dir> python -m pytest -q -p absent_all
    61 passed, 14 skipped          # against 75 passed, 0 skipped on this machine

**The fourteen, and they are not one kind.** This is the finding that makes the item tractable.
A fixture does not fix all of them, and for three of them a fixture would be a lie.

| kind | bars | what the bar does | does a committed fixture restore it? |
|---|---|---|---|
| **A — restatement** | C14, C31, C39, C42, C44, C49, C50, C59, C60 | Re-derives a value *here* and compares it against a value read next door. The arithmetic is this repository's; only the reference is upstream | **Yes, completely.** A dated snapshot of the upstream reference restores the comparison, and the upstream-executing path becomes a provenance check on top |
| **B — live drift watch** | C7, C9, C37 | Watches a property of another repository that can *change* — the one-way edges, `EXEMPT_FIELDS` being still `{}`, the foreclosure still in curvecast's ledger | **No, and it must not.** Freezing the watched value into a fixture is precisely what defeats a drift watch. These are correct to skip; what is wrong is that nothing says so |
| **C — tool gate** | C58, C58b | Runs ruff through a resolved binary | Partly. There is already a `PATH` fallback, so any `pip install ruff` restores them. The pinned selection lives in `pyproject.toml`, so the gate cannot drift with ruff's defaults |

C61 is the proof the Kind-A fix works: it checks the spectrum against constants committed in
`test_views.py` rather than by reaching next door, and it is the one D6 bar that **does not** skip.
The retrofit generalises what C61 already does.

**What closed it.** All three parts landed, as a rider, at the size the precedent allows.

1. **The census, as an equality.** `ENVIRONMENT_CONDITIONAL` in `tests/test_environment_census.py`
   declares every conditional bar with its kind and reason, held at equality by C72 and mutated by
   C72b. C73 then runs the whole suite in a child interpreter under `tests/absent_machine.py` and
   requires the observed skips to **equal** the declaration — because a static scan could be wrong
   in exactly the direction that matters, and a bar may skip for a reason no AST can see.
2. **The certificate, and it is not a snapshot of upstream.** `tests/upstream_certificate.py`
   records *this* repository's side of each comparison, on a date, against named sibling commits.
   C59 is what forced that shape: copying curvecast's fixture would have C59 compare deskcraft's
   panel against a copy of deskcraft's panel — 7,044 rows duplicated to assert nothing. All nine
   Kind-A bars now run everywhere, and the certificate is held at equality against the live parse
   whenever a sibling IS present, so the committed copy cannot be the thing that drifts.
3. **Kind B declared permanently conditional**, with the reason on each entry (DD70).

**The count was wrong, and the correction is the finding.** Fourteen bars skipped; **eighteen are
conditional**. Four lose a check off-machine *without skipping* — C6 since D3a and C61 since D6,
both of which already carried an `if ...exists():` around their provenance half, plus the two the
retrofit created. No skip census could have found any of them, which is why the census declares
`PARTIAL` alongside `SKIPS`. A bar that quietly does less is invisible in a way a skip is not.

**Acceptance, met.** A clean machine reports **74 passed, 7 skipped** — three Kind-B watches, two
ruff gates, two import-contract gates — and an eighth turns C72 and C73 red. On this machine:
**81 passed, 0 skipped**. Both counts were fixed in the rider's §2 before the code was written.

**Landed as a rider, not a row.** The precedent held: D4's row records *"C58/C58b, the lint gate,
which rides along and is not D4"*. The freeze stays at twenty-one, and the one-in-one-out swap
this item was flagged as a candidate for was **not needed**.

## X3. `dominant_share` over-attributes, and D7b will rank legs with it before D9 fixes it — CLOSED

**Measured, at D6 §6.4.** The six grammar terms are not orthogonal, and the Gram matrix travels on
the basis so this can be checked rather than assumed:

    LEVEL . REAL_VS_NOMINAL   +0.4434
    LEVEL . CROSS_MARKET      +0.2717
    CURVATURE . CROSS_MARKET  -0.3005

`LEVEL` leads `REAL_VS_NOMINAL` by **4.991%** and `CROSS_MARKET` by 10.756%; the three carry
**83.43%** of the book's absolute loading and sit within 11% of each other, because all three are
substantially the same nominal duration counted through overlapping directions.

**Which flag this is, widened 2026-09-15 by `AMENDMENT_A3` §7 (DD96).** This item named only
§2's **F4**, and F4 is the lesser half of it. F4 wants a *partial contribution* — a conditional
correlation rather than a raw pairwise one — which is a different object and is D9's to build.
**F3 wants exactly the decomposition that does not exist.** §2 calls F3 *"the important one"* and
says *"only the fidelity-versus-risk split exposes it"*, and the fidelity side of that split is
`dominant_share`. So the non-orthogonality bites F3 **harder** than F4, and the flag §2 calls
important is the one this item did not mention. Widened rather than opened as a second entry, on
curvecast's D414/D421 precedent — both of those ended by widening a guard instead of adding one.
