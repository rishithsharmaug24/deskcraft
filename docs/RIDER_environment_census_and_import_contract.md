# Rider — the environment census, the upstream certificate, and the import-contract gate

*Written 2026-09-15, at `740f97a`, before any of the code it describes. Closes carried items
**X1** and **X8** in `docs/CARRIED_ITEMS.md`.*

**This is not a package.** It rides along with the next one, in the shape D4's row records for
the lint gate — *"C58/C58b, the lint gate, which rides along and is not D4."* The build order
stays frozen at twenty-one core packages under `AMENDMENT_A1` §6, one-in-one-out; nothing here
asks for a row, scores a claim, or consumes a package slot.

**It is deliberately not named `PRECOMMIT_deskcraft_<package>_*.md`.** C34 reads package closure
from exactly that glob. A rider that matched it would tell the claims register a package had
closed, which is the opposite of true.

New ids: bars **C72, C72b, C73, C74, C74b, C75**; decisions **DD69–DD72**.

Everything in §1 was counted before this document existed. The counting is what made the work
tractable, and two of the four counts changed the plan.

### 0.1 Fourteen bars, and they are not one kind

A pytest plugin rebinds the module-level sibling-path constants after collection, so every bar
takes its own absent branch with no file in the tree touched:

    61 passed, 14 skipped        # against 75 passed, 0 skipped on this machine

| kind | bars | what it does | can a committed fixture restore it? |
|---|---|---|---|
| **A — restatement** | C14, C31, C39, C42, C44, C49, C50, C59, C60 | Re-derives a value *here*, compares against one read next door | **Yes.** The arithmetic is this repository's; only the reference is upstream |
| **B — live drift watch** | C7, C9, C37 | Watches a property of another repository that can *change* | **No, and it must not** |
| **C — tool gate** | C58, C58b | Runs a resolved binary | Partly — a `PATH` fallback already exists |

### 0.2 The count that changed the design — what a Kind-A fixture can honestly contain

The first plan was *"a dated upstream snapshot holding every upstream value those bars read."*
For C59 that is 7,044 rows × 8 fields — and C59's whole assertion is that deskcraft's committed
panel and curvecast's fixture are **the same bytes**. A snapshot generated by copying the
upstream file would make the bar compare deskcraft's panel against a copy of deskcraft's panel,
which asserts nothing, and would double a large fixture to do it.

**So the certificate holds digests of *this* repository's side, not copies of upstream** (DD69).
Each entry says: *on this date, with curvecast at this commit, deskcraft's side of this
comparison hashed to X, and the comparison passed.* Off-machine the bar re-derives its own side
and checks the hash. That detects every drift on the side the archive actually contains.

**What it cannot detect, stated rather than papered over:** upstream moving afterwards. That is
not a gap the certificate could close — a reviewer holding only `git archive HEAD` cannot see
curvecast either. Upstream drift is Kind B's job, Kind B is *correctly* conditional, and §0.3
is why.

### 0.3 Why three bars must keep skipping

C7 watches that no upstream file imports deskcraft. C9 watches that curvecast's `EXEMPT_FIELDS`
is still `{}`. C37 watches that the foreclosure is still in curvecast's ledger. **Freezing a
watched value into a fixture is precisely what defeats a drift watch** (DD70). A committed copy
of `EXEMPT_FIELDS == {}` would be green forever, including on the day curvecast amends it —
which is the single failure C9 exists to catch, and the reason this repository exists at all.

These three are correct to skip. What is wrong today is only that **nothing says so**.

### 0.4 The gate that no bar invokes

Found while counting the skips, proposed by nobody. Every package row since D1 quotes
`lint-imports` output; D6's says *"19 files, 47 dependencies, 2 kept, 0 broken."* **No test in
this repository runs it.** One boundary bar reads the contracts out of `[tool.importlinter]` and
asserts things about their shape; C7 scans the direction the tool structurally cannot see. The
tool itself is a hand-run, and every "0 broken" in every row is a number a human typed.

That is worse than a skip. A skip appears in pytest's output; a gate that is never invoked
leaves no evidence at all — and this one guards the boundary the repository's premise rests on.

## 1. What is built

### 1.1 `tests/upstream_certificate.py` (DD69)

The dated certificate. Carries the generation date, both sibling commits, the eight entries
above, and a `digest()` helper shared by every bar that reads it — shared rather than copied,
so a bar and its certificate cannot compute a hash two different ways.

### 1.2 Nine Kind-A bars gain an else-branch

Each keeps its upstream comparison verbatim and gains a fallback. The shape is the same
everywhere:

- upstream present → the full comparison runs **and** the certificate is checked, so the
  certificate cannot go stale silently;
- upstream absent → the bar re-derives deskcraft's side and compares against the certificate.

**The bars stop skipping.** They become *partially* conditional — the restatement always runs,
the provenance half does not — and the census declares exactly that (§1.4).

### 1.3 `tests/absent_machine.py`

The plugin from §0.1, moved inside the tree so the archive carries the instrument rather than
only a description of it.

*(**Annotated 2026-09-29 — DD245.** Carrying the instrument was not enough: it only worked in the
author's folder. The plugin chose which modules to rebind by whether their path contained the
words `deskcraft` and `tests`. That describes this disk, not the suite. Unpacked into a folder with
any other name, it rebound nothing, and C73 went red on a reviewer's machine. Five of its seven
declared skips ran against the real curvecast and the real ruff and lint-imports tools. This was
found while the public copy was built in a staging folder, and reproduced at `8baeada` in a copy
named `reviewer_copy`. **DD245: the plugin takes the suite's directory from its own file**, and
**C226** checks that against a folder with another name.)*

### 1.4 `tests/test_environment_census.py` — C72, C72b, C73, C75 (DD72)

`ENVIRONMENT_CONDITIONAL` is an **equality**, in the shape `ENGINE_IMPORT_ROOTS` and `MODULES`
already use here. Every environment-conditional bar is declared with its kind and its reason:
`SKIPS` (does not run at all) or `PARTIAL` (runs, minus its provenance half). A floor would
notice only shrinkage, and today nothing would notice a fifteenth.

- **C72** — a static AST scan finds every conditional bar three ways: it reaches a
  `pytest.skip`, or it calls a certificate helper, or it names an upstream path constant. The
  discovered mapping must **equal** the declaration.
- **C72b** — the scan, mutated: a new skipping bar, a new bar touching curvecast, and a
  near-miss that must not fire.
- **C73** — the clean machine, for real. Spawns a child interpreter under the §1.3 plugin and
  requires the observed skip set to equal the declared `SKIPS`, node id for node id. This is
  what keeps the static census honest.
- **C75** — every certificate entry is read by some bar. An entry nobody reads is a stale
  claim wearing a gate's clothes.

### 1.5 `tests/test_import_contract.py` — C74, C74b (DD71)

X8, in exactly C58/C58b's shape, for exactly C58b's reason.

*(**Annotated 2026-09-22 — DD132.** Both bars went red on this machine, and not on anything
either of them is about. `lint-imports.exe` is a pip-generated console script — an unsigned,
per-venv launcher stub that does nothing but call `importlinter.cli:lint_imports_command` — and
Application Control now refuses **it**, by name, in Code Integrity event 3077, while allowing
both the interpreter beside it and the `importlinter` library that interpreter imports. It
reproduces at `8b7e5dc`, so it predates every change made this week and is not intermittent in
the way the 2026-09-11 `.pyd` block was.*

*The bars did not resolve to a skip, which is the part worth recording. `_lint_imports()`
selected on `candidate.exists()` — and the stub does exist — so the skip branch was never
reached and the `OSError` landed inside `subprocess.run`, before any assertion. **DD132: the
resolver asks whether the tool can be run, not whether a launcher is present**, probing each
candidate with `--help` and falling back from the launchers to the interpreter plus the entry
point that `entry_points.txt` declares. Same tool, same 1.10.0, same configuration; only the
launcher differs. The fallback is deliberately **not** a skip — a gate reporting nothing while
looking like it reported something is C58b in a third tool. The skip survives for the one case
it was written for, no route to the tool at all.*

*What this was actually about: while the two bars were red, the only evidence that the boundary
held was a number a human had typed — which is the state **X8** was opened to end, reached the
long way round. Green again, from the bar: **2 kept, 0 broken**, 21 files, 65 dependencies. No
bar is added and no claim changes; a restored verdict is not a new one.*

***C73 caught the repair's own side effect in the sweep that introduced it**, which is the part
of this worth keeping. `absent_machine` blanks the sibling repositories by rebinding named
candidate lists, and DD132 created a third list it did not know about — so under the simulation
the two bars found the real interpreter and **ran where the census declares they skip**. The
plugin's own comment had already named this failure: a second list that must agree is a third
thing to keep in step, and it is always the copy that drifts. It drifted inside the hour.
`INTERPRETER_CANDIDATES` is now in `UPSTREAM_CANDIDATE_LISTS`. A static reading of the suite
could not have seen this; only running a child could, which is the claim C73 was written to
make and the first time it has been paid.)*

- **C74** — resolves `lint-imports` through the same candidate list plus `PATH`, runs it with
  `PYTHONPATH` at `src/`, and asserts the exit code distinguishes *clean* from *did not run*.
  Kept and broken counts are held at declared equalities: **2 kept, 0 broken**.
- **C74b** — the mutation. A generated config forbidding a module the engine genuinely imports,
  through the same invocation, must report the break. *curvecast's gate once went green on a
  ruff that never ran* (2026-09-09); a gate whose mutation has never fired is a gate held on
  trust.

## 3. What this rider does not close

Stated here so the register does not have to discover it later.

- **Upstream drift is still invisible off-machine**, by construction (§0.2). The certificate
  bounds this repository's side and says nothing about curvecast's.
- **The certificate is regenerated by hand.** There is no `scripts/` here and there cannot be
  (DD58), so regeneration is a bar's provenance half telling you it is stale, and a person
  acting on that. The failure is loud, which is the property that matters.
- **C73 spawns the suite inside the suite.** It deselects the census module in the child, so it
  cannot recurse — but the cost is a second collection on every run.
- **X2, X3, X4, X5, X6 are untouched.** They belong to D7a, D7b, D8 and D9, and they need those
  packages' pre-commits, not this one.

## 4. Amendment, same day, after the above was committed at `0e19ecd`

Bars **C76, C76b**; decision **DD73**. Suite **81 → 83**. `tests/test_carried_items.py`.

**Why it was not in §1.** It does not close a carried item; it protects the five that remain. The
register's §3 admitted the failure — *"if an owning package closes without discharging its item,
that is a silent failure this file does not catch — nothing parses it"* — and admitting a
failure in prose is where this repository usually starts writing a gate, not where it stops.

**What it does.** C34's logic, pointed at a second document: if the package owing an open item
has landed, its pre-commit must carry `**Xn** — discharged:` or `**Xn** — carried to <D>:`. A
carry is followed to a fixed point, so an item can be moved but not dropped. The register's new
§4 declares the form.

**Predictions, fixed before the code.**

- **P6.** No existing bar turns red, D4's wording again. **Held** — 83 passed.
- **P7.** C76 passes **vacuously**: none of D7a, D7b, D8, D9 or D17 has landed, so nothing is
  owed an answer and the real arm judges nothing. **Held**, and it is why C76b carries the whole
  demonstration rather than being a formality beside it.
- **P8.** The census does not change: the new module names no sibling path and reads no
  certificate entry, so C72 still finds **18** conditional bars and C73 still **7** skips.
  **Held.**

**What it deliberately does not do.** It cannot judge whether an answer is *good*. A pre-commit
saying *"X4 — discharged: we looked at it"* passes. The register's content is still held by
whoever reads it; what a bar now holds is that nobody gets to skip the reading.
